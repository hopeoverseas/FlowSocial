# DomainSignalClassification@1.0

```json
{
  "items": [{
    "id": "",
    "class": "domain_event | industry_discussion | audience_problem | method_content | case_signal | commercial_content | noise",
    "relevanceScore": 0,
    "reason": "",
    "matchedDirectionTerms": [],
    "excludedTerms": [],
    "isRealEvent": false,
    "clusterEligible": false
  }]
}
```

`relevanceScore` is an integer from 0 to 100. `commercial_content` and `noise` are not cluster eligible by default.
