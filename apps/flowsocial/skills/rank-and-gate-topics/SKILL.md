# 审核与门控选题

作为独立主编审核节点处理候选母选题。生成模型负责发散，本 Skill 负责删减和阻断。

## 输入要求

要求输入包含 `candidate_topics[]`、相关 `event_clusters[]`、账号定位、目标受众、评分阈值和禁写规则。执行前读取 [contract.md](references/contract.md)。

## 工作流

1. 检查每个 `core_claim` 是否被候选引用的证据直接支持。
2. 检查是否只有热点复述、是否具有明确读者价值。
3. 合并或淘汰重复选题，保留证据更强且角度更具体者。
4. 对结合选题复核真实交集和强行结合风险。
5. 执行账号、受众、伦理、营销和时效门控。
6. 只输出保留、降级和淘汰决定；需要修改时列出 `required_changes`，不得悄悄改写候选。

## 默认门槛

- 综合分低于 70：淘汰。
- 证据强度低于 60：降级为 `needs_research`。
- 强行结合风险高于 50：原则上淘汰。

调用方传入阈值时使用调用方配置，并在输出记录实际阈值。

## 边界

- 不创建新选题，不修改 Evidence，不联网补证据。
- 不生成平台子选题、标题、正文或图片。
- 不把常识当作缺失证据。
