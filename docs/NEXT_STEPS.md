# FlowSocial 下一步任务

状态日期：2026-10-03。本文件维护优先级、目标、验收、范围、命令和风险；执行结果只更新 [PROGRESS.md](PROGRESS.md)。普通验证使用 Node.js 24.18.0，命令均在 `apps/flowsocial` 目录执行。没有授权/精确版本/预算时不运行 live 脚本。

## P0-1 合成轻结构改单夹具与隔离回归

- **目标**：解除 `xhs-light-revision-self-test` 对活动/私人 SQLite 中完整 Provider 计划的依赖，保持原验证强度。
- **验收**：夹具完全由确定性输入构造，覆盖至少三页的权威计划/不可变 page revision；不导入活动 storage；保留文字锁定、regenerate/edit、精准原图、视觉确认失效、费用/checkpoint、零自动重试和历史不可变断言；干净环境完整套件一次执行退出 0。
- **影响范围**：该测试及共享测试 helper、隔离 runner；不改变业务合同、seed 或历史数据。
- **测试命令**：`npm run test:xhs-light-revision`（仅隔离环境）；`npm run test:offline`。
- **风险**：伪造不足的 fixture、跳过断言或复制私人 DB 会造成假通过。任一失败必须保留原错误，不增加隐性 Provider 调用。

## P0-2 静态资产范围与费用入口边界

- **目标**：只通过静态入口提供明确的前端资源，关闭绕过原子权威计划/审批/预算的泛化图片付费入口。
- **验收**：主页和已知前端资源正常；data、源码、上传、产物、点文件、编码路径和符号链接逃逸均失败关闭；使用惰性 fake transport 证明受限请求零 Provider 调用；真实原子生产/审阅/选择流程仍通过。
- **影响范围**：静态 HTTP 路由、旧泛化图片 API 和旧 content-tasks 生图/重试/修订付费接口、代表性 HTTP 测试、[兼容/迁移记录](../apps/flowsocial/docs/migrations/http-static-and-image-boundaries.md)；不放宽主链版本、预算或人工门禁。
- **测试命令**：`npm run check`；`npm run test:offline`（包含新增 HTTP 安全回归）；安全单测可在隔离环境运行 `node scripts/tests/http-security-boundaries-self-test.mjs`。
- **风险与兼容**：直接访问源码/运行目录或旧图片入口的调用方需改用受控 API；必须列出响应变化、下游替代和回退方式，回退不能重新开放敏感目录或无审批付费。

## P1-3 真实业务验收输入与双平台人工闭环

- **目标**：先填好[验收输入清单](operations/business-acceptance.md)，再按冻结策略、精确账号和版本验证真实内容质量、人工发布与指标回收。
- **验收**：五个人类产品门各有精确对象与确认人；Provider 请求/重试/费用上限与未知效果对账规则明确；用户选择确切文章/页面/图片版本；每个平台实际发布证据和 72h/7d 指标绑定该版本。缺失指标为 null，本地包/模拟记录不算真实发布。
- **影响范围**：账号、策略、内容、授权引用与私有证据；需要业务数据时另行授权私有迁移，不能读取或提交客户数据/凭据来“补全”源码。
- **验证命令**：先 `npm run test:offline`；只有真实验收输入和授权齐备后，才为具体场景选择对应 `scripts/live/` 命令及调用预算。本文件不预授权任何真实调用。
- **风险/停止条件**：IP 白名单未独立确认、授权范围不明、费用无法确定、版本 stale、效果未知或预算耗尽时停止，保留证据并对账；禁止自动重试。团队公网部署不属于本项本地验收。
