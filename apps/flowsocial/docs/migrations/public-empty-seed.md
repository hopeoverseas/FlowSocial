# 公开源码的空初始化种子

2026-10-12：公开发布只包含新建的 `defaults/store.json` 空种子。本机 `data/` 全部忽略，原交接 seed、数据库、知识文件、图片、备份及发布证据不进入公开 Git 历史，也不被本次改动覆盖或删除。

## 初始化与兼容

仅在 SQLite 尚无 `app_state` 时初始化，按以下顺序选择来源：

1. `FLOWSOCIAL_DATA_DIR` 指定目录中的本机 `store.json`。
2. 应用目录原有本机 `data/store.json`。
3. 随源码分发的 `defaults/store.json` 空种子。

已有 SQLite 状态继续使用原状态，种子或代码变动不会重置它。保留前两项兼容原本机数据流程；新克隆不含它们，使用第三项创建空工作台。数据库结构、不可变历史、人工选择/发布确认、预算和平台权限均未修改。

## 影响与测试

全新克隆无需获取原交接数据即可启动。需要业务数据的运营者仍须走独立私有迁移和授权，不能把业务状态写入 `defaults/store.json` 后公开。

离线测试使用专属临时目录和合成种子，覆盖：无私有种子时回退到公共空种子；独立数据目录优先；原本机 seed 兼容；已有 SQLite 状态不会被后续种子覆盖。完整回归入口为 `npm run test:offline`，专用用例为 `node scripts/tests/public-seed-bootstrap-self-test.mjs`。

## 回退

原有带 seed/数据库的本机工作区可以恢复旧加载顺序，数据无需迁移或回滚。公开新克隆必须保留公共空种子回退，不能为兼容而重新提交本机 `data/`；若初始化异常，修复公共种子结构或加载逻辑，禁止用活动数据库/客户数据替换它。回退代码不删除或重建已有 SQLite。
