# Xiaohongshu analysis guide

Analyze the note as one product: title, cover, first screen, body, page sequence, visual rhythm, tags, interaction, and CTA.

Return these optional `platformAnalysis` fields:

```json
{
  "titleCoverPromise": [],
  "firstScreenEntry": [],
  "cardSequence": [],
  "visualInformationRoles": [],
  "saveMechanism": [],
  "interactionAndCta": []
}
```

Distinguish recurring mechanisms from platform folklore. Do not infer hidden recommendation weights, fixed keyword density, posting time, or traffic thresholds.

Common candidate mechanisms include problem-solution, emotional resonance, counterintuitive viewpoint, before-after proof, identity projection, checklist/tutorial, and hotspot bridge. Do not force a sample into one of these labels when evidence is weak.

Account type matters. Separate the effect of an official brand, founder, employee expert/KOS, personal creator, and product/vertical account from the transferable content structure.

For company content, inspect whether the note performs discovery, authority, proof, solution, or action. A high-performing traffic note is not automatically suitable for product or lead-generation duties.
