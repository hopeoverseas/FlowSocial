# 方法选择政策

- 垂直专业起号：优先精准受众、专业认知和证据沉淀，适合业务边界清晰且能持续输出的账号。
- 热点桥接混合：允许直接相关和可自然桥接热点，必须解释热点如何连接目标受众问题。
- 受控热点实验：只用于短周期验证触达机制，必须监测目标用户占比和垂直内容回流；不能把完全无关热点作为默认打法。
- 公众号企业经营：重点是权威、内容资产、关系承接和有效线索，不以单篇爆文作为唯一成功标准。
- 公众号IP经营：必须有稳定发声者和真实判断来源。
- 矩阵：只推荐角色协同，不推荐重复铺量。公司事实与合规边界共享，账号身份、受众、语气、内容和承接隔离。
- 所有发布频率、比例和时段都是待验证假设，不是平台算法常量。
- 小红书打法优先解释发现流、搜索、视觉承载和互动场景如何匹配账号身份；公众号打法优先解释订阅关系、搜索沉淀、稳定栏目和私域承接如何匹配账号目标。
- 推荐打法不是唯一答案。每个平台同时保留备选打法，并用资源门槛、观察窗口和退出条件说明何时切换。
- 单账号模式只执行主账号；矩阵模式按角色拆分流量发现、专业权威、方案证明或转化承接，不允许多个账号使用完全相同的职能配比。
- 账号策略投影和内容计划必须继承打法版本与实验标识，确保后续内容结果可以回溯到具体决策。
