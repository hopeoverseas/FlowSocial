# 静态资源与旧生图入口边界

本次改动收紧本机 HTTP 服务的公开文件范围，并关闭没有精确版本、人工审批和调用预算的旧泛用生图接口。它没有执行 Provider 调用、平台上传、草稿创建或真实发布。

## 行为与兼容性

- 静态 GET/HEAD 只允许 `http/static-assets.mjs` 中的 11 个明确资源：页面、样式、3 个根目录浏览器脚本和 6 个 UI 脚本。页面中新增本地资源时，必须同时更新此清单并通过 HTTP 测试。
- `data/`、数据库、上传目录、交付工件、后端代码、配置、依赖和任意其他文件不再通过静态 URL 读取，统一返回 404。不存在目录或扩展名的广泛放行。
- 使用请求的原始路径检查点段和反斜杠，避免 URL 规范化隐藏穿越请求；畸形编码返回 404。公开文件或其子目录是符号链接时返回 404，包括指向应用目录内私有文件的链接。最终文件使用 `O_NOFOLLOW` 打开。
- 公开资源只支持 GET/HEAD，其他方法返回 405。响应保留 `no-cache`，增加准确长度和 `nosniff`。
- 原有 `/api/v1/` 分发和版本化产物预览、下载处理不受静态清单影响。产物消费者应使用既有 API 返回的 `previewUrl`、`downloadUrl`，不要依赖直接读取应用目录。
- `/api/v1/images/generate` 除原有 OPTIONS 预检外，返回 410 和 `UNGOVERNED_IMAGE_GENERATION_REMOVED`。它在读取请求体及调用 Provider 前拒绝，无法通过传入 prompt、旧模型、畸形 JSON 或客户端自报审批字段重新启用。
- 另外三条旧付费 POST 入口整体退役，返回 410 和 `LEGACY_PAID_CONTENT_GENERATION_REMOVED`：`/api/v1/content-tasks/{id}/assets/generate`、`/api/v1/content-tasks/{id}/visual-candidates/{pageId}/retry`、`/api/v1/content-tasks/{id}/revise`。旧 revise 会调用付费文本，并可能在修改图片规划时自动再生图，不能作为纯离线编辑保留。其付费实现已从 HTTP 入口移除，不保留隐藏自动调用路径。
- 上述拒绝和既有 ContentRun 退役分发均位于 `readStore()` 之前，不解析请求体、不读取业务状态、不执行持久化。启动服务仍会按原有规则初始化自身 SQLite，这不等于请求阶段读取或修改业务数据。
- 替代入口为 `/api/v1/unified-content-projects/{projectId}/platforms/xiaohongshu/provider-executions`。必须先完成现有主链的精确内容版本、Provider 计划、人工审批、调用次数和积分预算；并继续遵守功能开关、检查点、幂等和不确定结果核对规则。
- 图像单页修改须先使用现有 `.../light-revision-plans`，再完成对应人工审批与执行；标题、正文或上游改变须形成主链的不可变后继内容版本，通过 `/api/v1/content-agent/runs` 等现有主链入口重新走确认过程。不能把上述 URL 视为可直接替换旧请求体的快捷生图或任意文本编辑接口。

`api-client.js` 仍保留旧方法声明用于显式告知老调用者 410；当前浏览器 UI 没有使用旧 `generateImage`，旧内容编辑页面仍可能调用 `reviseContent` 等方法并收到 410。历史内容读取、版本列表、纯本地视觉方案编辑及既有受控原子主链保留。不得以静态文件开放、恢复旧接口或另造审批字段绕过主链。

## 迁移、影响范围与验证

没有数据库结构或存量数据迁移。重启本地服务即可加载新边界；运行时源签名包含新的静态边界模块。曾依赖 `/data/...`、`/artifacts/...` 或后端文件 URL 的外部脚本须迁移到既有 API；旧泛用生图、内容生图、重试及修订客户端须迁移到主链，并处理 410。没有自动迁移或覆盖旧内容快照。

新增测试在自有临时目录中只复制源码和公开资源，生成独立空数据种子，启动真实 HTTP 分发，使用惰性假生图函数和受控传输。子进程使用精简环境，不复制本地配置、业务数据或密钥；fetch、HTTP 和外部 socket 被阻断。所有临时文件均在测试结束后清理。

```sh
cd apps/flowsocial
node scripts/tests/http-security-boundaries-self-test.mjs
```

Node 24.18.0 验证通过：11 个公开资源可读；私有文件、原始及编码穿越、畸形编码、文件和目录符号链接被拒绝；4 条旧付费入口及既有 ContentRun 均返回 410，请求阶段的业务状态读取和持久化调用均为 0；受控生图仍拒绝关闭开关和缺失审批/精确权限的请求；假图片和文本 Provider 调用、受控传输调用及外网调用均为 0。完整主链、预览和交付回归仍由 `npm run test:product` 验证，不能用本测试替代真实业务验收。

## 回滚与剩余边界

这是一项暴露面修复。出现前端资源遗漏时，保留默认拒绝行为，增加经过审查的精确资源及对应测试，随后重启服务。产物 URL 不兼容时修复消费者或其既有 API，不能回滚为任意文件静态服务；旧生图、重试或修订不兼容时迁移调用者，不能恢复无精确版本、审批和预算的付费入口。不要仅恢复被删除的付费实现或删除提前拒绝分支；任何必要兼容方案必须复用主链安全门并补零调用负例。无需回滚数据库或更改历史内容快照。

此改动不建立用户登录、团队 RBAC、跨进程状态并发控制或统一 API Origin 校验；服务继续限于可信本机使用。没有扩大 Provider 调用授权，也没有解除公众号 `WECHAT_40164` 的 IP 白名单阻断或发布前人工确认。
