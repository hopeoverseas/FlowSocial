# 自然化文案

默认使用 `audit_only`。只有调用方明确传入 `rewrite_copy_only` 和可编辑范围时才返回修订文本。

## 输入要求

要求输入包含 `mode`、`platform`、原文、账号语气、`protected_spans[]`、不可变主张和允许修改范围。执行前读取 [contract.md](references/contract.md)。

## 审计维度

- 空泛开头、重复总结、机械分点和过度对称句式；
- 模板化转折、口号、营销套话和无信息形容词；
- 不符合平台的书面腔或过度网络化；
- 虚假的个人感受、过度确定性和假装引用；
- 段落节奏、语义重复和连接词堆叠。

## 改写流程

1. 先生成带位置和严重度的问题清单。
2. 只修改 `editable_ranges` 内的表达，不改变信息含义。
3. 保持数字、日期、名字、产品能力、引文、URL 和 claim/source ID 不变。
4. 不新增个人经历、案例、情绪、立场和事实。
5. 返回逐项变更日志，供后续事实复检。

## 边界

- 不使用文件原地覆盖模式。
- 不改变锁定标题、大纲、CTA、Markdown/HTML 结构。
- 不替代事实审核；改写后必须由编排器重新执行事实与引用校验。
